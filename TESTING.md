# Testing Guide — github-conflict-ai

## Prerequisites

```bash
pip install -r requirements.txt
pip install pytest pytest-asyncio
```

## 1. Unit Tests

Run the full test suite:

```bash
pytest tests/test_core.py -v
```

Run a specific test class:

```bash
pytest tests/test_core.py::TestFormatConflictSection -v
```

### What's covered

| Module | Tests |
|--------|-------|
| `models.py` | MergeConflict and ConflictReport creation, optional fields |
| `verify.py` | HMAC-SHA256 signature verification (valid, invalid, empty) |
| `github_comments.py` | Markdown formatting for merge, semantic, and mixed conflicts |
| `summarizer.py` | Conflict section formatting (none, empty, with conflicts, file truncation) |
| `semantic.py` | LLM JSON parsing (valid, markdown-wrapped, invalid, exception) |
| `git_ops.py` | Diff truncation utility |
| `events.py` | Event dispatch routing (PR, push, comment mention, unknown) |
| `github_app_auth.py` | JWT generation validation (missing app_id, missing key path) |
| `openai_compat.py` | Client fallback behavior (no key, no base, custom values) |

## 2. Manual End-to-End Testing

### 2.1 Start the server

```bash
uvicorn main:app --reload
```

Verify it's running:

```bash
curl http://localhost:8000/health
# Expected: {"status":"ok"}
```

### 2.2 Configure `.env`

Ensure your `.env` has:

```env
GITHUB_TOKEN=ghp_your_personal_access_token
GITHUB_APP_ID=your_app_id
GITHUB_PRIVATE_KEY_PATH=./your-app.pem
GITHUB_WEBHOOK_SECRET=your_webhook_secret

# LLM — remove these lines to use defaults, or set explicitly:
LLM_API_BASE=https://vjioo4r1vyvcozuj.us-east-2.aws.endpoints.huggingface.cloud/v1
LLM_API_KEY=test
LLM_MODEL=openai/gpt-oss-120b
```

### 2.3 Simulate a PR webhook

```bash
python scripts/simulate_webhook.py pull_request
```

**Expected behavior:**
1. Server logs: `Webhook received: event=pull_request`
2. Server logs: `Dispatching event=pull_request action=opened`
3. Server logs: `PR #1 on rohanh03/github-conflict-ai: feature-test-comment → main — running conflict scan`
4. Conflict detection runs (merge-tree + semantic analysis)
5. PR summary generated via LLM
6. Comment posted to PR with summary + conflict section

**Check for:**
- No `RuntimeError` about missing env vars
- No `401 Unauthorized` from LLM endpoint
- No `fatal: Not a valid object name` from git
- Comment on PR includes `## PR Summary` header
- Comment includes `Cross-Branch Conflicts` section (or `None detected`)

### 2.4 Simulate a push webhook

```bash
python scripts/simulate_webhook.py push
```

**Expected behavior:**
1. Server logs: `Push to feature-test-comment on rohanh03/github-conflict-ai`
2. Compares pushed branch against all open PRs
3. Posts conflict comments if any found

### 2.5 Test on-demand analysis

Comment `@conflict-ai` on an open PR. The bot should:
1. Re-run conflict detection for that PR
2. Post an updated conflict report

### 2.6 Verify GitHub comment output

After a successful PR webhook, check the PR on GitHub for:
- **PR Summary comment** with:
  - `## PR Summary` header
  - LLM-generated summary text
  - `**Stats:** X files changed · +Y / -Z`
  - `### Cross-Branch Conflicts` section (or `**Conflicts:** None detected`)
  - `---` footer with `Generated by [github-conflict-ai]`
- **Conflict Alert comment** (separate, if conflicts found) with:
  - `## Conflict Alert` header
  - Merge conflicts table
  - Logical conflicts with suggested fixes
  - Scan duration

### 2.7 Test without Slack

If `SLACK_WEBHOOK_URL` is empty or unset, Slack notifications should be silently skipped (no errors in logs).

## 3. Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `ModuleNotFoundError: No module named 'jwt'` | Missing PyJWT | `pip install PyJWT[crypto]` |
| `RuntimeError: GITHUB_APP_ID is not configured` | Missing `.env` value | Add `GITHUB_APP_ID=...` to `.env` |
| `401 Unauthorized` on LLM call | Wrong LLM config in `.env` | Remove `LLM_*` lines or set to hackathon URL |
| `fatal: Not a valid object name origin/<branch>` | Stale shallow clone | Delete `/tmp/conflict-ai-repos/` and retry |
| `TypeError: Issuer (iss) must be a string` | Old code without str cast | Pull latest — `str(app_id)` fix is in |
